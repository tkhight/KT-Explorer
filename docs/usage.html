KT_Explorer 使い方

タブ・タブグループ・ペイン表示を持つ、Windows 用のファイルブラウザです。

画面の構成

場所内容
メニューバー(上端)ファイル / 編集 / 表示 / お気に入り / 履歴 / ツール / ヘルプ。右端はペインのボタン(2ペイン・3ペイン・指定ペイン)
ツールバー戻る・進む・一つ上・更新・元に戻す・やり直し、パス欄、絞込欄、検索欄、プレビューの切り替え
グループバータブグループの切り替え。右端の「＋」で追加
左のツリーフォルダの階層。タブに連動して位置が変わります(オフにもできます)
タブバーと一覧開いているフォルダのタブと、その中身。一覧の下に件数や状態が出ます

選択とドラッグ

一覧では、アイコンと名前をドラッグするとファイルの移動・コピー、それ以外の場所をドラッグすると範囲選択になります。

今の選択に追加Ctrl を押しながらドラッグ

1 つずつ・連続で選ぶCtrl+クリック / Shift+クリック。全て選択は Ctrl+A

タブグループ

  • プロジェクトごとにタブをまとめます。グループバーの「＋」で追加、右クリックで名前の変更・色・削除。
  • グループ名をドラッグして並べ替えます。グループバー上のホイールで切り替えます。
  • グループに色を付けると、一覧の背景がごく薄いその色になります。
  • 「デフォルト」グループは削除できません。取り込んだエクスプローラーはここに入ります。

ペイン

絞り込みと検索

  • 絞込(Ctrl+F): 表示中の一覧を絞ります。Esc で解除。
  • 検索: 検索欄に入力して Enter。サブフォルダも探します。Esc で中断・解除。

条件は空白で区切って並べます(すべてを満たすものが残ります)。

書き方意味
report、"二語 以上"名前に含む
*.png、?.txtワイルドカード
-draft除外(どの条件にも - を付けられる)
type:画像画像・動画・音声・文書・圧縮・コード・フォルダー・ファイル
ext:png,jpg拡張子
size:>10MB、size:1MB..10MBファイルサイズ
date:今日、date:今週、date:7d更新日時
date:>2024-01-01日付の指定(範囲は ..)
content:語(中身:語)ファイルの中身。検索欄のみ(テキストの先頭 2 MB)

例: type:画像 size:>1MB date:今週

お気に入りと履歴

  • お気に入りメニュー: 今のフォルダを追加、クリックで開く、右クリックで新しいタブ・編集・削除。「お気に入りを整理…」で並べ替え・グループ・区切り線。
  • 履歴メニュー: 最近開いたフォルダと、よく開くフォルダ。Ctrl+クリックで新しいタブ。

取り込み・常駐・制約

  • Explorer の取り込み: 外部から開いたエクスプローラーを、デフォルトグループのタブにして閉じます(「PC」「ごみ箱」や複数タブのウィンドウは対象外)。
  • 常駐: 閉じるボタンでトレイに隠れます。完全に終了するには「ファイル」→「アプリケーションの終了」。
  • 仮想デスクトップ: 切り替えにウィンドウが追従します(最大 0.4 秒ほどの遅れ)。
  • 保存先: %AppData%\KT_Explorer\state.json(タブ、グループ、お気に入り、表示の設定、履歴など)。
  • ZIP の中身の閲覧には対応していません。ZIP は Windows の既定の動作で開きます。
  • タブを切り替えると、選択位置とスクロール位置は保持されません。
  • 大きなコピー・移動の進捗ダイアログが出ている間は、ウィンドウを操作できません。
