# KT_Explorer

タブ・タブグループ・ペイン表示を持つ、Windows 用のファイルブラウザです。
Tabracus のような使い方をベースに、プロジェクトごとにフォルダを整理して扱えるように作っています。

> 個人が開発しているソフトです。ファイルを操作するソフトなので、大事なデータはバックアップを取ったうえで、自己責任で使ってください(無保証。[LICENSE](LICENSE))。

使い方は [docs/usage.html](docs/usage.html) にまとめています。アプリの「ヘルプ」→「使い方」でも開けます。

## ダウンロードして使う

1. このリポジトリの **Releases** から `KT_Explorer-<版番号>-win-x64.zip` をダウンロードします。
2. 好きなフォルダに展開して、`KT_Explorer.exe` を実行します。インストールは不要で、.NET を入れる必要もありません(同梱しています)。
3. exe には署名が無いため、最初の起動で Windows の「Windows によって PC が保護されました」が出ることがあります。入手元を確認したうえで、「詳細情報」→「実行」で起動します。

**最初に知っておいてほしいこと**(「ツール」メニューで変えられます)

- 「開いた Explorer を取り込む」は、最初はオフです。オンにすると、デスクトップなどから開いたエクスプローラーのウィンドウは閉じて、KT_Explorer のタブになります。
- 「閉じるボタンでトレイに常駐」は、最初はオンです。完全に終了するには、「ファイル」→「アプリケーションの終了」を選びます。

**アンインストール**: 「ツール」の「Windows 起動時に自動起動」をオフにして終了し、展開したフォルダと、設定を保存している `%AppData%\KT_Explorer` を削除します。

## 特徴

- **タブとタブグループ**: タブをグループにまとめて、プロジェクトごとに切り替えられます。タブはグループ間で移動できます。
- **ペイン表示**: 2〜3 ペインを横に並べて表示します。ペインは一時的なもので、専用の「ペインタブ」として現在のタブの右隣に作られます。
- **全仮想デスクトップで一つのウィンドウ**: 仮想デスクトップを切り替えても、ウィンドウが追従します。
- **Explorer の取り込み**: デスクトップなどから開いたエクスプローラーを自動で取り込み、デフォルトグループのタブにします(オプション)。
- **アイコン**: 水色のフォルダを 2 つのペインに分けた図案(2 ペイン表示のイメージ)。exe・ウィンドウ・タスクトレイで同じアイコンを使います。
- **トレイ常駐**: 閉じるボタンでトレイへ隠れ、取り込みを働かせ続けます(オプション)。多重起動はしません。
- **ツリー**: 左端に表示します。項目は、名前の右側の空白をクリックしても選択でき、強調表示も行の右端まで広がります。アクティブなタブに合わせて位置が切り替わります(オプション)。右クリックで、一覧と同じ作りのメニュー(開く・新しいタブで開く・お気に入りに追加・切り取り/コピー/貼り付け・新規作成・名前の変更・削除・パスをコピー・ここでターミナルを開く・プロパティ・その他のオプション)が開きます。
- **お気に入り**: メニューバーの「お気に入り」に集約しています。開くと、「お気に入りに追加(現在のフォルダ)」「お気に入りを整理…」と、登録したフォルダの一覧が1つのメニューに出ます。一覧の項目をクリックすると現在のタブで開き、右クリックすると「新しいタブで開く」「編集」「削除」が選べます。「お気に入りを整理…」では、**並べ替え・グループ(メニューではサブメニュー)への分類・区切り線の追加**・編集・削除ができます(整理ウィンドウで編集して、「OK」で反映します。「キャンセル」なら、何も変わりません)。
- **表示の切り替え**: メニューバーの「表示」(上から、大アイコン / 中アイコン / 小アイコン / 一覧 / 詳細)、または `Ctrl+Shift+1`(詳細)・`2`(アイコン。いまの大きさ)・`3`(一覧)で、一覧の見た目を切り替えます。**詳細**は列のある表、**アイコン**は大きなアイコンを名前つきで折り返して並べ(画像・動画・文書などは、エクスプローラーと同じ**サムネイル**)、**一覧**は小さなアイコンと名前を、上から下へ列に折り返して並べます。表示は**タブ(ペイン)ごと**に持ち、終了しても保存されます。新しく開くタブは、最後に切り替えた表示で始まります。アイコン・一覧には列見出しが無いので、並べ替えは、「表示」メニューの「並べ替え」からも選べます。
- **メニューバー**: 画面の上端に、メニューバー(ファイル / 編集 / 表示 / お気に入り / 履歴 / ツール / ヘルプ)を置いています(ツール・ヘルプは、順に追加中)。右端には、ペインのボタン(▥2・▥3・指定ペイン)があります。ツールバーにあった「★ お気に入り」「表示」「履歴」のボタンは、同じ名前のメニューに移しました。**編集**: 元に戻す / やり直し / 切り取り / コピー / 貼り付け / 削除(ごみ箱へ)/ 全て選択。一覧にフォーカスがあるときは、選択したファイル・フォルダへの操作(`Ctrl+Z` `Ctrl+Y` `Ctrl+X` `Ctrl+C` `Ctrl+V` `Delete` `Ctrl+A` と同じ)で、パス欄・絞込欄・検索欄などの入力欄にフォーカスがあるときは、その入力欄の文字への操作になります(いま使えない項目は灰色になります)。**ファイル**: ターミナルで開く(選択が 1 つのフォルダならその中で、そうでなければ表示中のフォルダで)/ WinMerge(選択が 2 つならその 2 つを比較。ペインが 2 つ以上あれば、操作中のペインと右隣のペインのフォルダを比較。それ以外は WinMerge を起動するだけ)/ 新規作成(フォルダー・テキスト ドキュメント。作ったあと、その場で名前を入力)/ プロパティ(選択が 1 つならその項目、そうでなければ表示中のフォルダ)/ アプリケーションの終了(トレイに常駐せず、終了する)。
- **オーバーレイアイコン**: アイコンの上に、OneDrive の同期状態(雲・チェック)、TortoiseSVN の状態、ショートカットやリンクの矢印などを重ねて表示します(エクスプローラーと同じ、Windows のシェルのオーバーレイを使います。詳細・アイコン・一覧のすべてで表示)。表示されている項目だけをバックグラウンドで調べるので、画面は止まりません。一覧を読み直したとき(ファイルの変化を検知したときなど)に、状態を調べ直します。重いときは、「表示」メニューの「オーバーレイアイコンを表示」をオフにできます(終了しても保存)。
- **ツリーの仮想化**: ツリーは、画面に見えているノードだけを作ります。サブフォルダが数千あるフォルダ(`%TEMP%` など)でも、開いたときの重さや、メモリが増えません。フォルダの移動に合わせて選択したノードは、見える位置まで自動でスクロールします(深い階層・遠い位置でも)。
- **ツリーとタブのアイコン**: ツリーのノードと、フォルダタブの左に、フォルダのアイコンを表示します(ペインタブは、タイトルの `▥` で表します)。ドライブ・デスクトップ・ダウンロード・ドキュメントなどは、それぞれ固有のアイコンです。ツリーとタブにも、OneDrive・SVN などのオーバーレイが付きます(「表示」メニューの「オーバーレイアイコンを表示」のオフで、ツリー・タブ・一覧のすべてから消えます)。フォルダごとにアイコンを変えている(`desktop.ini`)場合の個別のアイコンは、表示しません。
- **アイコンの大きさ**: 「表示」メニューの「大アイコン」「中アイコン」「小アイコン」、または、アイコン表示で `Ctrl` を押しながらホイールで、大きさを変えられます(全タブ共通。終了しても保存)。読み込んだサムネイルは記憶されるので、別のフォルダへ移って戻っても、すぐに出ます。
- **フォルダのサイズの記憶**: 計算したフォルダのサイズは 5 分間記憶し、戻ったときに計算し直しません。ファイル操作(コピー・移動・削除・名前の変更・新規作成)や、フォルダの変更の検知で、関係するフォルダの記憶だけを捨てます。
- **履歴**: メニューバーの「履歴」(「お気に入り」の右隣)に、**最近開いたフォルダ**と、**よく開くフォルダ**(開いた回数つき)が出ます。クリックで現在のタブ、`Ctrl`+クリックで新しいタブに開きます。存在しないフォルダは出しません。履歴は終了しても保存され(最大 300 件)、「履歴を消去」で消せます。
- **パス欄**: 入力中に、フォルダの**補完候補**が出ます(`C:\Us` → `C:\Users`。`↓` `↑` で選び、`Enter` で移動、`Tab` で入力欄に入れて次の階層へ、`Esc` で閉じる)。区切りの無い文字は、履歴から探します。入力していない間は**パンくず**(`C:\ ▸ Users ▸ me`)で表示し、階層をクリックでその階層へ、`▸` でその中のフォルダの一覧、`Ctrl`+クリックで新しいタブ、空いたところをクリック(または `Ctrl+L`)でパスの入力に切り替わります。
- **情報の列**: 詳細表示の列見出しを右クリックすると、**作成日時・属性(R: 読み取り専用 / H: 隠し / S: システム / A: アーカイブ)・画像のサイズ(幅 × 高さ。動画はフレームの大きさ)・再生時間(動画・音声)**の列を、追加・削除できます(全タブ共通。終了しても保存)。画像のサイズと再生時間は、列を出したときだけ、バックグラウンドで読み込みます。
- **統一したフラットなデザイン**: ツールバー・ペインのボタン・プレビュー・グループタブ・フォルダタブ・「＋」は、枠のない、同じ規則の見た目です。普通は背景なし、カーソルを乗せると淡い水色、押した・オンのときは少し濃い水色、使えないときは薄い灰色。メニューバー右端の「2ペイン」「3ペイン」「指定ペイン」は、ペインの図柄のアイコン(2 分割・3 分割・4 分割)で、カーソルを合わせると説明が出ます。「プレビュー」は、右にパネルのある図柄の切り替えボタン(オンは水色)。グループタブは、フォルダタブと見分けられるように、**全周を囲む丸い形**です(選択中は、太めの枠と薄い背景。色なしは、灰色の枠で、選択中が青い枠と薄い青の背景)。フォルダタブは、選択中が白い背景で、上に青い細線(タブの色は、今までどおり下の線)。ピン留めは、青い小さなピンのアイコンです。
- **入力欄・ペインタブ・ツリー・一覧の見出し(フラットなデザインの続き)**: パス欄・絞込・検索の入力欄は、角の丸い細い灰色の枠で、カーソルを乗せると枠が濃くなり、入力中は青い枠と、下に青い線が出ます。パンくずも同じ枠で、階層の名前にカーソルを乗せると淡い水色になります。ペインタブは、タイトルの先頭に、ペインの図柄のアイコン(2 分割)が付きます(以前の文字の `▥` は無くなりました)。ツリーの選択中(フォーカスあり)は、枠なしの濃い水色です。一覧の列見出しは、立体的なボタンをやめ、フラットな白に細い下線で、カーソルを乗せると淡い水色になります(列幅の変更は、そのまま使えます)。
- **メニューのデザイン**: メニューバーと、開いたメニュー、アプリが出す右クリックのメニュー(タブ・ツリー・パンくずなど)を、同じフラットな見た目にしました。メニューバーの見出しは、普通は背景なし、カーソルを乗せると淡い水色、開いている間は濃い水色。開いたメニューは、白い背景に、角を丸めた細い灰色の枠と、ごく薄い影で、項目にカーソルを乗せると淡い水色になります。使えない項目は薄い灰色、チェックは左に青いチェックマーク、サブメニューは右端に `›`、ショートカットは右端に小さな灰色の文字です。(Windows が出す、一覧やツリーの標準の右クリックメニューは、Windows のままです。)
- **ツールバーのアイコン**: 戻る・進む・一つ上の階層へ・更新・元に戻す・やり直しと、タブバーの「新しいタブ」(＋)は、Windows 標準のアイコン(Windows 11 は Segoe Fluent Icons、Windows 10 は Segoe MDL2 Assets のフォント)で表示します。使えないときは灰色になります。カーソルを合わせると、操作名とショートカットが出ます。
- **プレビュー**: ツールバーの「プレビュー」、「表示」メニュー、または `Alt+P` で、一覧で選択したファイルの内容を、右側に表示します。画像(大きいものは縮小して読み込み)、テキスト(先頭の 64 KB。UTF-8・BOM つき・UTF-16・Shift-JIS を自動判定)、フォルダ(中身の数)、そのほか(種類・大きさ・日時)に対応します。複数選択のときは件数だけを表示します。幅はスプリッターで変えられ、表示の有無と幅は終了しても保存されます。
- **ファイル操作**: コピー・切り取り・貼り付け、削除(ごみ箱)、名前の変更、新規作成、ドラッグ&ドロップに対応しています。標準のエクスプローラーとの間でもコピー&ペースト、ドラッグ&ドロップができます。
- **元に戻す / やり直し**: コピー・移動・削除(ごみ箱)・名前の変更・新規作成を、`Ctrl+Z` / `Ctrl+Y` で戻したりやり直したりできます。
- **エクスプローラーと同じ名前の変更**: 一覧の上で名前を直接編集できます(`F2`、または選択した名前をゆっくり2回クリック)。
- **Windows 標準の右クリックメニュー**: 「その他のオプション」から、エクスプローラーと同じメニュー(7-Zip、Git、「送る」「プログラムから開く」などの拡張を含む)を呼び出せます。
- **自動更新**: 表示中のフォルダの変更(ファイル操作や、他のアプリでの変更)を検知して、一覧を自動で更新します。
- **絞り込みと検索**: 表示中の一覧を、名前だけでなく、**種類・サイズ・更新日時の条件**でも絞り込めます(下の「絞り込みの条件」を参照)。`*` と `?` が使える再帰検索もあります。検索欄にも、絞込と**同じ条件**(`type:画像 size:>1MB date:今週` など)が使え、さらに**ファイルの中身**を探す `content:語`(または `中身:語`、`本文:語`)が使えます(テキストファイルの先頭 2 MB。UTF-8・BOM つき・UTF-16・Shift-JIS を判定し、バイナリは対象外。`-content:語` で含まないもの。例: `ext:cs content:TODO`)。検索結果の一覧で、名前の変更・削除・貼り付けなどのファイル操作をすると、同じ検索をやり直して、結果に反映します。
- **マウスジェスチャとショートカット**: アプリ自身が持っているので、設定なしで使えます。

## 動作環境

- Windows 10 / 11(Windows 11 で開発・動作確認)
- 配布している zip を使う場合は、追加で入れるものはありません(64 ビット版の Windows)
- 自分でビルドする場合は [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

## ビルドと起動

```powershell
git clone https://github.com/tkhight/KT-Explorer.git
cd KT-Explorer
dotnet run --project src/KT_Explorer
```

実行ファイルだけを作る場合は、次のとおりです。

```powershell
dotnet build src/KT_Explorer -c Release
```

出力は `src/KT_Explorer/bin/Release/net8.0-windows/` に作られます。

## 使い方

### 基本操作

| 操作 | 方法 |
|---|---|
| フォルダを開く | 一覧でダブルクリック / Enter。**リンク先がフォルダのショートカット(.lnk)**も同じで、エクスプローラーを開かず、この一覧のままリンク先を表示します(右クリックの「新しいタブで開く」も使えます)。ファイルへのショートカットや、リンク先が無いものは、従来どおり、関連付けで開きます |
| 戻る / 進む | `Alt+←` / `Alt+→`、ツールバーのボタン、マウスのサイドボタン |
| 一つ上の階層へ | `Alt+↑`、一覧で `Backspace`、ツールバーのボタン |
| 名前で項目へ移動 | 一覧で文字を入力(その文字で始まる名前の項目を選択。続けて入力すると絞り込まれ、少し間を置くとリセット) |
| 更新 | `F5` |
| パス欄へ移動 | `Ctrl+L`(パスを入力して Enter) |
| 絞り込み | `Ctrl+F`(解除は `Esc`)。条件の書き方は、下の「絞り込みの条件」 |
| プレビューの表示・非表示 | `Alt+P`、ツールバーの「プレビュー」、「表示」メニューの「プレビューを表示」 |
| 検索 | 「検索:」欄に入力して Enter(中断・解除は `Esc`) |
| 表示の切り替え | メニューバーの「表示」(大・中・小アイコン / 一覧 / 詳細)、`Ctrl+Shift+1`(詳細)/ `2`(アイコン)/ `3`(一覧)。アイコン・一覧では、矢印キーで、見た目どおりの上下左右へ動けます |
| 並べ替え | 列見出し(名前・更新日時・種類・サイズ)をクリック(アイコン・一覧では、「表示」メニューの「並べ替え」から)。もう一度クリックすると昇順 / 降順が入れ替わり、見出しに ▲ ▼ が付く。**並び順はタブ(ペイン)ごと**に持ち、終了しても保存される。新しく開くタブは、最後にクリックした並び順で始まる |
| フォルダのサイズを見る | フォルダを右クリック → 「フォルダーのサイズを計算」(複数選択も可)。一覧の空白を右クリック → 「フォルダーのサイズをすべて計算」。「ツール」メニューの「フォルダーのサイズを自動計算」をオンにすると、一覧を開くたびに自動で計算する |

### ファイル操作

| 操作 | 方法 |
|---|---|
| コピー / 切り取り / 貼り付け | `Ctrl+C` / `Ctrl+X` / `Ctrl+V`(右クリックメニューからも)。**操作中のタブ・ペイン**に働きます(キーボードフォーカスが、タブバーやペインの枠に残っていても大丈夫です)。そのため、タブ A でコピーして、タブ B をクリックした直後に貼り付けると、タブ B に貼り付きます。ペイン A でコピーして、ペイン B のヘッダー(枠)をクリックしてから貼り付けると、ペイン B に貼り付きます。パス欄・絞込欄などの文字の入力中や、ツリーにフォーカスがあるときは、これまでどおりです |
| ツリーのフォルダを新しいタブで開く | ツリーのフォルダを **`Ctrl`+クリック**(いまのタブは動きません)。右クリックの「新しいタブで開く」でも開けます。展開の矢印のクリックは、これまでどおり |
| 削除(ごみ箱へ) | `Delete` |
| 完全に削除 | `Shift+Delete`(確認が出ます) |
| 名前の変更 | `F2`、または選択済みの名前をゆっくり2回クリック(一覧の上で直接入力) |
| 新しいフォルダー | `Ctrl+Shift+N` |
| 右隣のペインへコピー | `Ctrl+Shift+C` |
| 右隣のペインへ移動 | `Ctrl+Shift+M` |
| 新規作成(フォルダー / テキスト ドキュメント) | 一覧の空白を右クリック → 「新規作成」 |
| パスをコピー / プロパティ | 項目を右クリック |
| 右クリックメニューを 1 文字で実行 | 一覧・ツリーの右クリックメニューを開いて、見出しの( )の文字を押す。`O` 開く、`E` 新しいタブで開く(空白では更新)、`T` 切り取り、`C` コピー、`P` 貼り付け、`M` 名前の変更、`D` 削除、`A` パスをコピー、`I` ターミナル、`R` プロパティ、`W` 新規作成(→ `F` フォルダー / `T` テキスト)、`Z` フォルダーのサイズ、`F` お気に入りに追加(ツリー)、`Y`/`V` 反対のペインへコピー/移動、`G` WinMergeで比較、`X` その他のオプション |
| WinMerge で比較 | 一覧で 2 つ選んで右クリック →「WinMergeで比較」。ペイン表示では、左右のペインで 1 つずつ選んで右クリック →「反対のペインの選択と比較」(右隣のペインが相手。操作中のペインが左側)。ファイル同士かフォルダー同士のときだけ出る |
| 元に戻す / やり直し | `Ctrl+Z` / `Ctrl+Y`(`Ctrl+Shift+Z` でも可)、ツールバーの「元に戻す」「やり直し」のアイコン |

- **名前の変更**はエクスプローラーと同じ操作です。ファイルは拡張子を除いた部分が選択された状態で始まり、`Enter` か他の場所のクリックで確定、`Esc` で取り消します。ファイル名に使えない文字は入力できません。新しいフォルダーを作ったときも、その場で名前を入力できます。
- コピー・移動・削除は Windows 標準の機能で実行するため、進捗の表示、同名ファイルがあるときの確認、ごみ箱が標準のエクスプローラーと同じように働きます。同じフォルダへコピーすると「- コピー」の名前で作られます。
- **範囲選択**: 一覧の左右の余白、下の空いた部分、更新日時・種類・サイズの列からドラッグすると、枠が出て、重なった項目が選ばれます(詳細・アイコン・一覧のどの表示でも)。`Ctrl` を押しながらなら、今の選択に追加します。一覧の上下の端の外へ出して止めると、自動でスクロールします。`Esc` で取り消し、余白のクリックで選択を解除します。
- **ドラッグ&ドロップ**: 項目のアイコンか名前をドラッグして、別のペイン、一覧のフォルダ、左のツリー、タブへドロップできます。複数選択のまま、まとめてドラッグできます。
  - 何も押さずにドロップ: 同じドライブなら移動、違うドライブならコピー(標準と同じ)
  - `Ctrl` を押しながら: コピー / `Shift` を押しながら: 移動
- **元に戻す / やり直し**は、どのタブ・ペインで行った操作も、実行した順に戻せます。名前の変更や移動を取り消す(やり直す)と、そのフォルダを表示していたタブ・ペインも、元の名前・場所(やり直しなら新しい名前・場所)へ追従します。ツールバーのボタンにカーソルを合わせると、次に戻す操作が表示されます。
  - コピー: 作られた項目をごみ箱へ入れます(中身が失われないように、完全には削除しません)。やり直しでもう一度コピーします。
  - 移動: 元の場所へ戻します。
  - 削除(ごみ箱へ): ごみ箱から元の場所へ復元します。
  - 名前の変更、新規作成も戻せます。
  - **戻せないもの**: `Shift+Delete` の完全な削除、同名ファイルを上書きしたとき(上書きされた側)、同名があって別名になった移動。これらは履歴に記録しません。
  - 元の場所に同じ名前の項目があるなど、状態が変わっていて戻せないときは、理由を表示します。その操作は履歴から外れます。
  - 履歴は最大 50 件で、アプリを終了すると消えます。名前の入力欄やパス欄などに文字を入力している間は、`Ctrl+Z` は文字の入力側の取り消しに使われます。
- フォルダを、そのフォルダ自身の中へコピー・移動することはできません。
- 検索結果の一覧でも操作できます。名前の変更・削除・貼り付けなどのあとは、同じ検索をやり直して反映します(`Esc` か `F5` で通常の一覧へ戻ります)。

### 右クリックメニュー

項目または一覧の空白を右クリックすると、KT_Explorer のメニューが開きます。

- メニューの末尾の「**その他のオプション**」を選ぶと、Windows 標準のメニュー(エクスプローラーの「その他のオプションを確認」と同じもの)が開きます。
- **`Shift` を押しながら右クリック**すると、KT_Explorer のメニューを出さずに、最初から標準のメニューを(`Shift` で出る拡張項目つきで)開きます。
- 標準のメニューの「名前の変更」「切り取り」「コピー」「削除」「貼り付け」「開く(フォルダ)」は、KT_Explorer 自身の処理に置き換えて実行します(別のエクスプローラーを開いたりしません)。それ以外(プロパティ、7-Zip、送る、など)は Windows がそのまま実行します。
- Windows 11 の新しい形式のメニュー(上段にアイコンが並ぶもの)は、他のアプリから呼び出せないため再現できません。「その他のオプション」の従来形式のメニューになります。
- 別々のフォルダにある項目をまとめて選んでいるとき(検索結果など)は、標準のメニューは使えません。
- 「**ここでターミナルを開く**」は、そのフォルダを作業フォルダにしてターミナルを開きます(一覧のフォルダ・一覧の空白・ツリーのフォルダで使えます)。Windows Terminal があればそれを、なければ PowerShell を使います。
- **ツリーの右クリック**も同じ作りです。「貼り付け」はそのフォルダの中へ貼り付けます。「新規作成 → フォルダー」は、そのフォルダの中に作って、その場で名前を入力します(`Esc` で、既定の「新しいフォルダー」のまま)。「名前の変更」(ツリー上で `F2` でも)も、ダイアログではなく、ツリーの項目がその場で入力欄に変わります(全選択の状態で始まり、`Enter` か他の場所のクリックで確定、`Esc` で取り消し。ファイル名に使えない文字は入力できません)。「名前の変更」「削除」(ごみ箱へ)は、そのフォルダを開いているタブ・ペイン、お気に入り、ツリーにも反映されます(名前を変えると表示は新しい名前に追従し、削除すると、開いていたタブは残っている最も近い親フォルダへ移ります)。ドライブのルートなど、親を持たないものには使えません。キーボードのメニューキーでも開けます(選択中のフォルダが対象)。`Shift` を押しながら右クリックすると、標準のメニューを直接開きます(ツリーでは「開く」だけを、このタブで開くものに置き換えます)。
- フォルダの空白部分の標準メニューには、「貼り付け」「表示」「並べ替え」は含まれません(これらは KT_Explorer のメニューにあります)。

### タブ

| 操作 | 方法 |
|---|---|
| 新しいタブ | `Ctrl+T`、「＋」ボタン、ツリーの右クリック → 「新しいタブで開く」 |
| タブを閉じる | `Ctrl+W`、タブの右クリックの「タブを閉じる」、タブを中クリック(タブに「✕」は付いていません) |
| 閉じたタブを開き直す | `Ctrl+Shift+T`、タブの右クリック → 「閉じたタブを開き直す」(元のグループの元の位置に開く。直近 20 件まで。フォルダが無くなっていれば、その前に閉じたもの) |
| タブを複製 | タブの右クリック → 「タブを複製」(右隣に同じフォルダのタブを作る。ペインタブはペインの構成ごと。色は引き継ぐが、ピン留めは引き継がない) |
| パスのコピー | 長いパスでパス欄に収まらなくても、右クリックでコピーできる。パンくずを右クリック →「パスをコピー」(階層の上なら、その階層までのパスも)、パス欄を右クリック →「パス全体をコピー」、タブを右クリック →「パスをコピー」。一覧・ツリーの右クリックの「パスをコピー」は従来どおり |
| タブを複数段で表示 | 「表示」メニューの「タブを複数段で表示」。オンにすると、フォルダタブが幅に収まらないとき、横にスクロールさせず、次の段へ折り返して、すべてのタブが見えるようになる(段の数は、タブの数と幅で決まる)。オフ(既定)は、1 段で、あふれた分は横にスクロール。オン/オフは保存される。グループバーは対象外 |
| ピン留め | タブの右クリック → 「タブをピン留め」(外すときは「ピン留めを外す」)。留めたタブは 📌 が付き、そのフォルダから別のフォルダへ移動すると(フォルダを開く・上へ・パス欄・パンくず・ツリー・お気に入りなど)、そのタブは動かず、移動先が右隣の新しいタブで開く。ペインタブは対象外。**ピン留めされたタブは閉じられません**(右クリックの「タブを閉じる」は選べず、中クリック・`Ctrl+W`・ロッカーも効きません。ピン留めされたタブを含むグループも削除できません。閉じるには、先にピン留めを外します)。状態として保存される |
| タブの色 | タブの右クリック → 「タブの色」。24 色の格子から選ぶ(色の名前は、カーソルを乗せると出る)、「色なし」、「その他の色…」(Windows の色の選択画面で、好きな色)。タブの下に色の線と、薄い背景が付く。状態として保存される |
| タブの切り替え | タブバー上でマウスホイール、`Ctrl+Tab` / `Ctrl+Shift+Tab` |

### タブグループ

- タブバーの上にグループバーがあります。右端の「＋」で追加し、右クリックで、名前の変更・色・削除ができます。グループには、タブの数は表示しません。
- **並べ替え**: グループ名を、別のグループ名の位置へドラッグ&ドロップします。「デフォルト」グループも、移動できます(位置が変わっても、デフォルトのままです)。並び順は保存されます。
- **色**: グループの右クリック →「グループの色」(タブの色と同じ、24 色の格子・「色なし」・「その他の色…」)。グループタブの枠がその色になり、選択中は背景もその色の薄いものになります。保存されます。
- **一覧の背景**: 表示中のグループに色があると、一覧(詳細・アイコン・一覧)の背景が、その色を**ごく薄く**(約 6%)したものになり、詳細表示の列見出しの行は、濃く(約 24%)なります。どんな色を選んでも、文字は読めます。色の無いグループは白です。ペインは、下の「ペインの色」のとおりです。
- グループバー上でマウスホイールを回すと、グループを切り替えられます。
- タブの並び順は、**タブを別のタブの上へドラッグ&ドロップ**して変えられます(ドロップしたタブの位置へ入ります)。
- タブを別のグループへ移すには、**タブをグループ名へドラッグ&ドロップ**するか、タブを右クリックして「グループへ移動」を選びます(フォルダタブもペインタブも同じ)。移動すると、**移動先のグループが表示され、移したタブがアクティブ**になります。
- 「デフォルト」グループは削除できません。外部から開いたエクスプローラーの取り込み先です。

### ペイン

- メニューバーの右端の「2ペイン」「3ペイン」(ペインの図柄のアイコン)を押すと、現在のタブの右隣に**ペインタブ**ができ、アクティブなフォルダが右側に追加されます。
- 同じく右端の「指定ペイン ▾」からは、ペインを**まとめて作る**ダイアログが開きます。**既存タブから選択…**: タブの一覧にチェックを付け、**2 つか 3 つ**選んだ状態で「作成」を押すと、そのタブのフォルダでペインができます(最初は、何もチェックされていません。3 つ選ぶと、残りはチェックできません。一覧の各行は、そのタブのグループの色の背景と、グループ名の名札で表示します)。**フォルダを指定…**: フォルダを **2 つか 3 つ**入力(または「参照…」で選択)した状態で「作成」を押すと、そのフォルダでペインができます(存在しないフォルダは赤くなり、「作成」は押せません)。どちらも、現在のタブの右隣に、新しいペインタブとして作られます。
- 各ペインのヘッダーの「✕」で、そのペインを閉じます。ペインが 1 つになると、ペインタブは閉じて元のタブへ戻ります。
- **ペインの色(参照元のグループ)**: ペインの一覧・列見出し・ヘッダーは、そのペインが**どのグループから来たか**の色になります。参照元のグループがあるペインには、ヘッダーにグループ名の名札が付きます。
  - 「指定ペイン → 既存タブから選択」: 選んだタブのグループ。別々のグループのタブを選ぶと、ペインごとに色が変わります。
  - 「2ペイン」「3ペイン」: 今のグループ。
  - 「指定ペイン → フォルダを指定」: 参照元なし(表示中のグループの色。名札は無し)。
  - 参照元のグループの色や名前を変えると、ペインも追従します。ペイン内でフォルダを移動しても、参照元は変わりません。参照元のグループを削除すると、参照元なしに戻ります。
- 選択した項目は、右クリックの「反対のペインへコピー / 移動」(3 ペインのときはペインごとの項目)か、`Ctrl+Shift+C`(コピー)/ `Ctrl+Shift+M`(移動)で、別のペインのフォルダへ送れます。ショートカットの宛先は右隣のペインで、右端のペインからは左端へ戻ります。
- ペインの間の境界線(スプリッター)を左右にドラッグすると、ペインの幅を変えられます。幅の最小は 120 です。
- 操作中のペインは青枠で示され、ツールバーやパス欄はそのペインに対して働きます。
- ペインは一時的なものなので、終了時に保存されません。ペインの幅は、ペインを増やす・閉じても、ドラッグで変えた比率を保ちます(新しく増えたペインは、既存のペインの平均の幅になります)。

### マウスジェスチャ

右ボタンを押したままドラッグします。

| 方向 | 動作 |
|---|---|
| 左 | 戻る |
| 右 | 進む |
| 上 | 一つ上の階層へ |

40px 未満の動きは、通常の右クリック(メニュー表示)になります。

**右ボタン+ホイール**: 右ボタンを押したままホイールを回すと、**上へ回すと左のタブ、下へ回すと右のタブ**へ切り替わります(1ノッチごとに 1 つ。端からは反対の端へ回り込み、タブバーのホイールと同じ動き)。**`Ctrl` も押していると、上=前のタブグループ、下=次のタブグループ**へ切り替わります(グループバーのホイールと同じ動き)。使ったあとに右ボタンを離しても、右クリックのメニューは出ません。

**ロッカー(右ボタンを押したまま左クリック)**: 右ボタンを押したまま左ボタンをクリックすると、**いま表示しているタブを閉じます**(最後の1枚は閉じません。「閉じたタブを開き直す」で戻せます)。右ボタンを離しても、右クリックのメニューは出ません。

「ツール」メニューのジェスチャのオン/オフに、どちらも従います。

> 注意: StrokesPlus などの、マウスジェスチャの常駐ツールが、右ボタンの操作を先に横取りしている場合は、KT_Explorer に届きません(そのツールの設定で、KT_Explorer を除外してください)。

### 絞り込みの条件

「絞込」欄には、空白で区切って、複数の条件を書けます。**すべてを満たす**項目だけが残ります(件数は、一覧の下に「絞り込み: 12 / 40 件」と出ます。解釈できない条件は、無視して、理由を表示します)。

| 書き方 | 意味 |
|---|---|
| `report` | 名前に含む(大文字小文字は区別しない) |
| `*.png`、`?.txt` | 名前全体のワイルドカード |
| `"二語 以上"` | 空白を含む名前(引用符で囲む) |
| `-draft`、`-type:画像` | その条件を満たさないもの(どの条件にも `-` を付けられる) |
| `type:画像` | 種類: 画像・動画・音声・文書・圧縮・コード・フォルダー・ファイル(`image`、`video`、`folder` なども可) |
| `ext:png,jpg` | 拡張子 |
| `size:>10MB`、`size:<=500KB`、`size:1MB..10MB` | ファイルサイズ(単位は B・KB・MB・GB・TB)。サイズを計算していないフォルダーは、サイズの条件に合わない |
| `date:今日`、`昨日`、`今週`、`今月`、`今年` | 更新日時(今週は月曜日から) |
| `date:7d`、`date:7日` | 7日以内に更新 |
| `date:>2024-01-01`、`date:2024-01-01..2024-03-31` | 日付で指定(`>` `>=` `<` `<=`、範囲) |

例: `type:画像 size:>1MB date:今週`(今週更新した、1MB を超える画像)、`*.log -error`。

「検索」欄では、これらに加えて、ファイルの中身の条件 `content:語` も使えます(読み込みが重いため、絞込欄では使えません)。

### 設定(メニューバーの「表示」「ツール」)

設定(オン/オフ)の項目は、メニューバーの 2 つのメニューに分かれています。

| メニュー | 項目 | 内容 |
|---|---|---|
| 表示 | ツリーをタブに連動 | タブを切り替えるたびに、ツリーの位置も追従する |
| 表示 | プレビューを表示 | 一覧で選択したファイルの内容を、右側に表示する(`Alt+P` でも切り替え。ツールバーの「プレビュー」ボタンでも同じ) |
| 表示 | フォルダーを先頭にまとめる | オンのとき、どの列で並べ替えてもフォルダーを先頭に置く(既定はオン) |
| ツール | マウスジェスチャ(右ドラッグ) | ジェスチャのオン/オフ(右ボタン+ホイール、ロッカーも同じ) |
| ツール | 開いた Explorer を取り込む | 外部から開いたエクスプローラーをデフォルトグループへ取り込む |
| ツール | 閉じるボタンでトレイに常駐 | オフにすると、閉じるボタンでアプリを終了する |
| ツール | 同じ名前のタブに親フォルダ名を表示 | 同じグループに、同じ名前で場所の違うフォルダタブがあるとき、名前の後ろに親フォルダの名前を灰色で添える(親も同じなら、違いが出る階層。名前の重なりが無くなれば消える。ペインタブは対象外)。既定はオン |
| ツール | フォルダーのサイズを自動計算 | オンにすると、一覧を開いたとき、フォルダーの合計サイズをバックグラウンドで計算して「サイズ」列に表示する(フォルダーが多い場所やネットワークドライブでは重くなるため、既定はオフ。ジャンクションなどのリンクはたどらない) |
| ツール | Windows 起動時に自動起動 | サインイン時に、ウィンドウを開かずトレイに常駐した状態で起動する(現在のユーザーのスタートアップに登録。管理者権限は不要) |

(以前は、ツールバーの「設定 ▾」ボタンにまとまっていましたが、上のメニューへ振り分け、ボタンは無くしました。)

トレイアイコンの右クリックメニューからも、取り込みの切り替えと終了ができます。

## Explorer の取り込みについて

- 新しく開かれたエクスプローラーのウィンドウを検知し、表示しているフォルダをデフォルトグループのタブにして、元のウィンドウを閉じます。
- 同じフォルダのタブがすでにあれば、そのタブを表示します。
- 「PC」「ごみ箱」などの特殊フォルダと、複数タブのウィンドウは取り込まず、そのまま残します。
- 元のウィンドウが一瞬見えることがあります。
- KT_Explorer が起動している間(トレイ常駐中を含む)だけ働きます。

## 保存される設定

`%AppData%\KT_Explorer\state.json` に、次の内容を保存します。

- タブとタブグループの構成、選択中のタブ
- ウィンドウの位置とサイズ
- お気に入り(グループ・区切り線を含む整理後の構成)
- 一覧の表示(詳細・アイコン・一覧。タブごと。新しいタブの初期の表示としても覚える)
- プレビューの表示の有無と幅
- 並べ替えの列と向き(タブごと。新しいタブの初期の並び順としても覚える)
- 「表示」「ツール」メニューの設定項目
- アイコンの大きさ、詳細表示で追加した列
- 開いたフォルダの履歴(パス・開いた回数・最後に開いた日時。最大 300 件)

## 既知の制約

- タブを切り替えるたびに一覧が作り直されるため、選択位置やスクロール位置は保持されません。
- 仮想デスクトップへの追従は 400ms ごとの確認です。切り替えから最大 0.4 秒ほど遅れます。
- Windows 標準の右クリックメニューは、従来形式のもの(「その他のオプション」)のみです。Windows 11 の新しい形式のメニューは再現できません。
- シェル拡張(7-Zip など)は KT_Explorer のプロセスの中で動くため、拡張側に不具合があると KT_Explorer にも影響することがあります。
- 中身の検索は、ファイルを順に読むため、大きなフォルダでは時間がかかります(先頭の 2 MB だけを読みます)。
- 画像のサイズ・再生時間は、Windows が持つ情報を読むため、対応していない形式(コーデックが無い動画など)は、空になります。
- 大きなコピー・移動の間は、進捗ダイアログが出ている間、KT_Explorer のウィンドウは操作できません。
