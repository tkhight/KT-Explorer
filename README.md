# KT_Explorer

タブ・タブグループ・ペイン表示を持つ、Windows 用のファイルブラウザです。
Tabracus のような使い方をベースに、プロジェクトごとにフォルダを整理して扱えるように作っています。

> **開発中**です。現在はフォルダの閲覧・移動が中心で、ファイルのコピー・移動・削除・名前変更などの操作はまだありません。

## 特徴

- **タブとタブグループ**: タブをグループにまとめて、プロジェクトごとに切り替えられます。タブはグループ間で移動できます。
- **ペイン表示**: 2〜3 ペインを横に並べて表示します。ペインは一時的なもので、専用の「ペインタブ」として現在のタブの右隣に作られます。
- **全仮想デスクトップで一つのウィンドウ**: 仮想デスクトップを切り替えても、ウィンドウが追従します。
- **Explorer の取り込み**: デスクトップなどから開いたエクスプローラーを自動で取り込み、デフォルトグループのタブにします(オプション)。
- **トレイ常駐**: 閉じるボタンでトレイへ隠れ、取り込みを働かせ続けます(オプション)。多重起動はしません。
- **ツリー**: 左端に表示します。アクティブなタブに合わせて位置が切り替わります(オプション)。右クリックで「新しいタブで開く」。
- **お気に入り**: フォルダを登録して、すぐ開けます。表示名とパスを編集できます。
- **絞り込みと検索**: 表示中の一覧を名前で絞り込めます。`*` と `?` が使える再帰検索もあります。
- **マウスジェスチャとショートカット**: アプリ自身が持っているので、設定なしで使えます。

## 動作環境

- Windows 10 / 11(Windows 11 で開発・動作確認)
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)(ビルド・実行に必要)

## ビルドと起動

```powershell
git clone https://github.com/tkhight/KT_Explorer.git
cd KT_Explorer
dotnet run --project src/KT_Explorer
```

実行ファイルだけを作る場合は、次のとおりです。

```powershell
dotnet build src/KT_Explorer -c Release
```

出力は `src/KT_Explorer/bin/Release/net8.0-windows/` に作られます。

## 使い方

### 基本操作

| 操作 | 方法 |
|---|---|
| フォルダを開く | 一覧でダブルクリック / Enter |
| 戻る / 進む | `Alt+←` / `Alt+→`、ツールバーのボタン、マウスのサイドボタン |
| 一つ上の階層へ | `Alt+↑`、一覧で `Backspace`、ツールバーのボタン |
| 更新 | `F5` |
| パス欄へ移動 | `Ctrl+L`(パスを入力して Enter) |
| 絞り込み | `Ctrl+F`(解除は `Esc`) |
| 検索 | 「検索:」欄に入力して Enter(中断・解除は `Esc`) |

### タブ

| 操作 | 方法 |
|---|---|
| 新しいタブ | `Ctrl+T`、「＋」ボタン、ツリーの右クリック → 「新しいタブで開く」 |
| タブを閉じる | `Ctrl+W`、タブの「✕」、タブを中クリック |
| タブの切り替え | タブバー上でマウスホイール、`Ctrl+Tab` / `Ctrl+Shift+Tab` |

### タブグループ

- タブバーの上にグループバーがあります。「＋グループ」で追加し、右クリックで名前の変更と削除ができます。
- グループバー上でマウスホイールを回すと、グループを切り替えられます。
- タブを別のグループへ移すには、**タブをグループ名へドラッグ&ドロップ**するか、タブを右クリックして「グループへ移動」を選びます。
- 「デフォルト」グループは削除できません。外部から開いたエクスプローラーの取り込み先です。

### ペイン

- 「▥2」「▥3」を押すと、現在のタブの右隣に**ペインタブ**ができ、アクティブなフォルダが右側に追加されます。
- 「指定ペイン ▾」からは、**既存のタブ**を選ぶか、**フォルダを指定**して、右ペインとして追加できます。
- 各ペインのヘッダーの「✕」で、そのペインを閉じます。ペインが 1 つになると、ペインタブは閉じて元のタブへ戻ります。
- 操作中のペインは青枠で示され、ツールバーやパス欄はそのペインに対して働きます。
- ペインは一時的なものなので、終了時に保存されません。

### マウスジェスチャ

右ボタンを押したままドラッグします。

| 方向 | 動作 |
|---|---|
| 左 | 戻る |
| 右 | 進む |
| 上 | 一つ上の階層へ |

40px 未満の動きは、通常の右クリック(メニュー表示)になります。

### 設定(ツールバーの「設定 ▾」)

| 項目 | 内容 |
|---|---|
| ツリーをタブに連動 | タブを切り替えるたびに、ツリーの位置も追従する |
| マウスジェスチャ(右ドラッグ) | ジェスチャのオン/オフ |
| 開いた Explorer を取り込む | 外部から開いたエクスプローラーをデフォルトグループへ取り込む |
| 閉じるボタンでトレイに常駐 | オフにすると、閉じるボタンでアプリを終了する |

トレイアイコンの右クリックメニューからも、取り込みの切り替えと終了ができます。

## Explorer の取り込みについて

- 新しく開かれたエクスプローラーのウィンドウを検知し、表示しているフォルダをデフォルトグループのタブにして、元のウィンドウを閉じます。
- 同じフォルダのタブがすでにあれば、そのタブを表示します。
- 「PC」「ごみ箱」などの特殊フォルダと、複数タブのウィンドウは取り込まず、そのまま残します。
- 元のウィンドウが一瞬見えることがあります。
- KT_Explorer が起動している間(トレイ常駐中を含む)だけ働きます。

## 保存される設定

`%AppData%\KT_Explorer\state.json` に、次の内容を保存します。

- タブとタブグループの構成、選択中のタブ
- ウィンドウの位置とサイズ
- お気に入り
- 設定メニューの各オプション

## 既知の制約

- タブを切り替えるたびに一覧が作り直されるため、選択位置やスクロール位置は保持されません。
- 仮想デスクトップへの追従は 400ms ごとの確認です。切り替えから最大 0.4 秒ほど遅れます。
- Windows 起動時の自動起動には未対応です。
- ファイルのコピー・移動・削除・名前変更、右クリックのシェルメニューは未実装です。
- ペインのリサイズ、タブの並べ替えは未実装です。
