# KT_Explorer

タブ・タブグループ・ペイン表示を持つ、Windows 用のファイルブラウザです。
Tabracus のような使い方をベースに、プロジェクトごとにフォルダを整理して扱えるように作っています。

> **開発中**です。ファイルのコピー・移動・削除・名前変更などの基本操作に対応しています。

## 特徴

- **タブとタブグループ**: タブをグループにまとめて、プロジェクトごとに切り替えられます。タブはグループ間で移動できます。
- **ペイン表示**: 2〜3 ペインを横に並べて表示します。ペインは一時的なもので、専用の「ペインタブ」として現在のタブの右隣に作られます。
- **全仮想デスクトップで一つのウィンドウ**: 仮想デスクトップを切り替えても、ウィンドウが追従します。
- **Explorer の取り込み**: デスクトップなどから開いたエクスプローラーを自動で取り込み、デフォルトグループのタブにします(オプション)。
- **トレイ常駐**: 閉じるボタンでトレイへ隠れ、取り込みを働かせ続けます(オプション)。多重起動はしません。
- **ツリー**: 左端に表示します。アクティブなタブに合わせて位置が切り替わります(オプション)。右クリックで「新しいタブで開く」。
- **お気に入り**: フォルダを登録して、すぐ開けます。表示名とパスを編集できます。
- **ファイル操作**: コピー・切り取り・貼り付け、削除(ごみ箱)、名前の変更、新規作成、ドラッグ&ドロップに対応しています。標準のエクスプローラーとの間でもコピー&ペースト、ドラッグ&ドロップができます。
- **元に戻す / やり直し**: コピー・移動・削除(ごみ箱)・名前の変更・新規作成を、`Ctrl+Z` / `Ctrl+Y` で戻したりやり直したりできます。
- **エクスプローラーと同じ名前の変更**: 一覧の上で名前を直接編集できます(`F2`、または選択した名前をゆっくり2回クリック)。
- **Windows 標準の右クリックメニュー**: 「その他のオプション」から、エクスプローラーと同じメニュー(7-Zip、Git、「送る」「プログラムから開く」などの拡張を含む)を呼び出せます。
- **自動更新**: 表示中のフォルダの変更(ファイル操作や、他のアプリでの変更)を検知して、一覧を自動で更新します。
- **絞り込みと検索**: 表示中の一覧を名前で絞り込めます。`*` と `?` が使える再帰検索もあります。
- **マウスジェスチャとショートカット**: アプリ自身が持っているので、設定なしで使えます。

## 動作環境

- Windows 10 / 11(Windows 11 で開発・動作確認)
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)(ビルド・実行に必要)

## ビルドと起動

```powershell
git clone https://github.com/tkhight/KT_Explorer.git
cd KT_Explorer
dotnet run --project src/KT_Explorer
```

実行ファイルだけを作る場合は、次のとおりです。

```powershell
dotnet build src/KT_Explorer -c Release
```

出力は `src/KT_Explorer/bin/Release/net8.0-windows/` に作られます。

## 使い方

### 基本操作

| 操作 | 方法 |
|---|---|
| フォルダを開く | 一覧でダブルクリック / Enter |
| 戻る / 進む | `Alt+←` / `Alt+→`、ツールバーのボタン、マウスのサイドボタン |
| 一つ上の階層へ | `Alt+↑`、一覧で `Backspace`、ツールバーのボタン |
| 更新 | `F5` |
| パス欄へ移動 | `Ctrl+L`(パスを入力して Enter) |
| 絞り込み | `Ctrl+F`(解除は `Esc`) |
| 検索 | 「検索:」欄に入力して Enter(中断・解除は `Esc`) |

### ファイル操作

| 操作 | 方法 |
|---|---|
| コピー / 切り取り / 貼り付け | `Ctrl+C` / `Ctrl+X` / `Ctrl+V`(右クリックメニューからも) |
| 削除(ごみ箱へ) | `Delete` |
| 完全に削除 | `Shift+Delete`(確認が出ます) |
| 名前の変更 | `F2`、または選択済みの名前をゆっくり2回クリック(一覧の上で直接入力) |
| 新しいフォルダー | `Ctrl+Shift+N` |
| 右隣のペインへコピー | `Ctrl+Shift+C` |
| 右隣のペインへ移動 | `Ctrl+Shift+M` |
| 新規作成(フォルダー / テキスト ドキュメント) | 一覧の空白を右クリック → 「新規作成」 |
| パスをコピー / プロパティ | 項目を右クリック |
| 元に戻す / やり直し | `Ctrl+Z` / `Ctrl+Y`(`Ctrl+Shift+Z` でも可)、ツールバーの「↶」「↷」 |

- **名前の変更**はエクスプローラーと同じ操作です。ファイルは拡張子を除いた部分が選択された状態で始まり、`Enter` か他の場所のクリックで確定、`Esc` で取り消します。ファイル名に使えない文字は入力できません。新しいフォルダーを作ったときも、その場で名前を入力できます。
- コピー・移動・削除は Windows 標準の機能で実行するため、進捗の表示、同名ファイルがあるときの確認、ごみ箱が標準のエクスプローラーと同じように働きます。同じフォルダへコピーすると「- コピー」の名前で作られます。
- **ドラッグ&ドロップ**: 項目をドラッグして、別のペイン、一覧のフォルダ、左のツリー、タブへドロップできます。複数選択のまま、まとめてドラッグできます。
  - 何も押さずにドロップ: 同じドライブなら移動、違うドライブならコピー(標準と同じ)
  - `Ctrl` を押しながら: コピー / `Shift` を押しながら: 移動
- **元に戻す / やり直し**は、どのタブ・ペインで行った操作も、実行した順に戻せます。ツールバーのボタンにカーソルを合わせると、次に戻す操作が表示されます。
  - コピー: 作られた項目をごみ箱へ入れます(中身が失われないように、完全には削除しません)。やり直しでもう一度コピーします。
  - 移動: 元の場所へ戻します。
  - 削除(ごみ箱へ): ごみ箱から元の場所へ復元します。
  - 名前の変更、新規作成も戻せます。
  - **戻せないもの**: `Shift+Delete` の完全な削除、同名ファイルを上書きしたとき(上書きされた側)、同名があって別名になった移動。これらは履歴に記録しません。
  - 元の場所に同じ名前の項目があるなど、状態が変わっていて戻せないときは、理由を表示します。その操作は履歴から外れます。
  - 履歴は最大 50 件で、アプリを終了すると消えます。名前の入力欄やパス欄などに文字を入力している間は、`Ctrl+Z` は文字の入力側の取り消しに使われます。
- フォルダを、そのフォルダ自身の中へコピー・移動することはできません。
- 検索結果の一覧でも操作できますが、操作後に結果は自動では更新されません(`Esc` か `F5` で通常の一覧へ戻ります)。

### 右クリックメニュー

項目または一覧の空白を右クリックすると、KT_Explorer のメニューが開きます。

- メニューの末尾の「**その他のオプション**」を選ぶと、Windows 標準のメニュー(エクスプローラーの「その他のオプションを確認」と同じもの)が開きます。
- **`Shift` を押しながら右クリック**すると、KT_Explorer のメニューを出さずに、最初から標準のメニューを(`Shift` で出る拡張項目つきで)開きます。
- 標準のメニューの「名前の変更」「切り取り」「コピー」「削除」「貼り付け」「開く(フォルダ)」は、KT_Explorer 自身の処理に置き換えて実行します(別のエクスプローラーを開いたりしません)。それ以外(プロパティ、7-Zip、送る、など)は Windows がそのまま実行します。
- Windows 11 の新しい形式のメニュー(上段にアイコンが並ぶもの)は、他のアプリから呼び出せないため再現できません。「その他のオプション」の従来形式のメニューになります。
- 別々のフォルダにある項目をまとめて選んでいるとき(検索結果など)は、標準のメニューは使えません。
- フォルダの空白部分の標準メニューには、「貼り付け」「表示」「並べ替え」は含まれません(これらは KT_Explorer のメニューにあります)。

### タブ

| 操作 | 方法 |
|---|---|
| 新しいタブ | `Ctrl+T`、「＋」ボタン、ツリーの右クリック → 「新しいタブで開く」 |
| タブを閉じる | `Ctrl+W`、タブの「✕」、タブを中クリック |
| タブの切り替え | タブバー上でマウスホイール、`Ctrl+Tab` / `Ctrl+Shift+Tab` |

### タブグループ

- タブバーの上にグループバーがあります。「＋グループ」で追加し、右クリックで名前の変更と削除ができます。
- グループバー上でマウスホイールを回すと、グループを切り替えられます。
- タブの並び順は、**タブを別のタブの上へドラッグ&ドロップ**して変えられます(ドロップしたタブの位置へ入ります)。
- タブを別のグループへ移すには、**タブをグループ名へドラッグ&ドロップ**するか、タブを右クリックして「グループへ移動」を選びます。
- 「デフォルト」グループは削除できません。外部から開いたエクスプローラーの取り込み先です。

### ペイン

- 「▥2」「▥3」を押すと、現在のタブの右隣に**ペインタブ**ができ、アクティブなフォルダが右側に追加されます。
- 「指定ペイン ▾」からは、**既存のタブ**を選ぶか、**フォルダを指定**して、右ペインとして追加できます。
- 各ペインのヘッダーの「✕」で、そのペインを閉じます。ペインが 1 つになると、ペインタブは閉じて元のタブへ戻ります。
- 選択した項目は、右クリックの「反対のペインへコピー / 移動」(3 ペインのときはペインごとの項目)か、`Ctrl+Shift+C`(コピー)/ `Ctrl+Shift+M`(移動)で、別のペインのフォルダへ送れます。ショートカットの宛先は右隣のペインで、右端のペインからは左端へ戻ります。
- 操作中のペインは青枠で示され、ツールバーやパス欄はそのペインに対して働きます。
- ペインは一時的なものなので、終了時に保存されません。

### マウスジェスチャ

右ボタンを押したままドラッグします。

| 方向 | 動作 |
|---|---|
| 左 | 戻る |
| 右 | 進む |
| 上 | 一つ上の階層へ |

40px 未満の動きは、通常の右クリック(メニュー表示)になります。

### 設定(ツールバーの「設定 ▾」)

| 項目 | 内容 |
|---|---|
| ツリーをタブに連動 | タブを切り替えるたびに、ツリーの位置も追従する |
| マウスジェスチャ(右ドラッグ) | ジェスチャのオン/オフ |
| 開いた Explorer を取り込む | 外部から開いたエクスプローラーをデフォルトグループへ取り込む |
| 閉じるボタンでトレイに常駐 | オフにすると、閉じるボタンでアプリを終了する |
| Windows 起動時に自動起動 | サインイン時に、ウィンドウを開かずトレイに常駐した状態で起動する(現在のユーザーのスタートアップに登録。管理者権限は不要) |

トレイアイコンの右クリックメニューからも、取り込みの切り替えと終了ができます。

## Explorer の取り込みについて

- 新しく開かれたエクスプローラーのウィンドウを検知し、表示しているフォルダをデフォルトグループのタブにして、元のウィンドウを閉じます。
- 同じフォルダのタブがすでにあれば、そのタブを表示します。
- 「PC」「ごみ箱」などの特殊フォルダと、複数タブのウィンドウは取り込まず、そのまま残します。
- 元のウィンドウが一瞬見えることがあります。
- KT_Explorer が起動している間(トレイ常駐中を含む)だけ働きます。

## 保存される設定

`%AppData%\KT_Explorer\state.json` に、次の内容を保存します。

- タブとタブグループの構成、選択中のタブ
- ウィンドウの位置とサイズ
- お気に入り
- 設定メニューの各オプション

## 既知の制約

- タブを切り替えるたびに一覧が作り直されるため、選択位置やスクロール位置は保持されません。
- 仮想デスクトップへの追従は 400ms ごとの確認です。切り替えから最大 0.4 秒ほど遅れます。
- Windows 標準の右クリックメニューは、従来形式のもの(「その他のオプション」)のみです。Windows 11 の新しい形式のメニューは再現できません。
- シェル拡張(7-Zip など)は KT_Explorer のプロセスの中で動くため、拡張側に不具合があると KT_Explorer にも影響することがあります。
- 大きなコピー・移動の間は、進捗ダイアログが出ている間、KT_Explorer のウィンドウは操作できません。
- ペインのリサイズは未実装です。
